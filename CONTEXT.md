# Orchard glossary

- **Courier**: Pip, the playable orchard visitor.
- **Post**: the delivery selection and return screen.
- **Course**: the explorable floating orchard.
- **Delivery**: a selectable objective within the course.
- **Seed**: an amber collectible, reset on a new visit.
- **Spark**: a permanent reward for completing a delivery.
- **Visit**: one entry into a delivery, ending on collection or return to post.
